# Органайзер Про Web

Первая веб-версия для работы с данными Органайзера на компьютере.

## Что уже есть в v0.1
- Заметки: список + редактирование на большом экране.
- Проекты: основные поля, сроки и этапы.
- Финансы: отдельные доходы/расходы и баланс.
- Полноэкранный календарь со сроками проектов и этапов.
- Локальное хранение в браузере.
- Подготовленный слой синхронизации через Firebase Auth + Firestore.
- Вход через Google включается после добавления Firebase-конфигурации.

## Важно
Android v0.9.24 не меняется этой веткой. Веб-разработка идёт в `personal-organizer-web-v1`.

Для реальной двусторонней синхронизации следующим шагом нужно создать/подключить Firebase-проект, после чего Android получает такой же sync ID для записей и подключается к тем же коллекциям Firestore. Вложения будут храниться отдельно в Firebase Storage.

