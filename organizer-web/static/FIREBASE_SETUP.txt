ОРГАНАЙЗЕР ПРО — ПЕРВАЯ ОБЛАЧНАЯ СИНХРОНИЗАЦИЯ

Для реальной синхронизации Web v0.3.0 и Android v0.9.26 нужен один Firebase-проект.

1. Создать Firebase project.
2. В Authentication включить Email/Password.
3. Создать Firestore Database.
4. В Firestore Rules установить правила из organizer-web/firestore.rules и опубликовать их.
5. В Firebase Project settings скопировать:
   - Project ID
   - Web API Key
6. В веб-версии нажать «Синхронизация» и сохранить эти два значения.
7. На Android открыть Настройки → Синхронизация и указать те же Project ID и Web API Key.
8. Создать один аккаунт email/пароль и использовать его на обоих устройствах.

Первая версия синхронизирует вручную:
- заметки;
- проекты;
- этапы;
- финансы;
- напоминания.

Вложения пока остаются локальными, чтобы не упереться в ограничение размера одного документа Firestore. Автоматическую синхронизацию и Storage для вложений добавим следующим этапом.

Без Project ID и Web API Key приложение продолжает работать полностью локально.
