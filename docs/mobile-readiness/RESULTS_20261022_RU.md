## 1. Безопасная синхронизация D01–D03

- Общий подтверждённый снимок, SHA-256 и сравнение трёх версий каждой записи заменили выбор целой базы по максимальной дате. Сроки проектов/напоминаний не определяют приоритет.
- Независимые изменения объединяются; неоднозначные правки, удаления против правки и столкновения числовых ID останавливают обмен. Обе версии сохраняются и доступны для экспорта. Это не автоматическое разрешение всех конфликтов и не миграция в UUID.
- 409 повторно читает актуальную ревизию; он не очищает локальные изменения. Перед заменой есть повторная проверка локальных правок внутри SQLite-транзакции, проверка владельцев вложений и страховочная копия D14.
- Владельцем является подтверждённый сервером account subject. Привязка сохраняется при выходе и в несекретных metadata системной Android-копии, даже если внутренний общий снимок не восстановлен. Старая база не назначается новому subject с тем же email. Для старых копий без стабильного ID восстановить отсутствующую историю нельзя: там остаётся защита по известному email.
- Облачный JSON сразу формируется компактно без Base64 вложений/локальных предпочтений. Проверен набор из 8000 заметок, который допустим в компактном виде и выходит за лимит с отступами.
- Выход и экспорт конфликта не блокируют главный поток ожиданием сетевого координатора.

Подробности: [SYNC_SAFETY_RU.md](SYNC_SAFETY_RU.md).

## 3. Подготовка публикации

Подготовлены target/compile API 36; удаление аккаунта в Android с повторным паролем и подтверждением email; соответствующий серверный маршрут с отзывом старых JWT и защитой от конкурентного PUT; отдельная внешняя страница удаления; справка о данных RU/EN и черновик полной политики; скрытие содержания новых PIN-защищённых напоминаний и запрос PIN при открытии.

Серверный код проверен локально/в CI и **не развёртывался на Render**. Работа функции на действующем сервере и публичный URL удаления не подтверждены. Реальные аккаунты/данные не использовались и не удалялись. Версия 0.9.38 (71), Android identity/настройки подписи и схема пользовательской SQLite не изменены. iOS-проект/сборка и публикация отложены.

До публичного релиза остаются защищённое хранение токена/PIN с проверенной миграцией (D10), фактические сроки/копии Render и полная privacy policy, согласованный серверный выкат и обновление старых клиентов, финансовые/UI/permission дефекты из отчёта, проверка подписанной Android-версии на устройствах и release AAB. Это выполненная подготовка и проверенные исправления, не готовая отправка в магазин. План: [PUBLICATION_PREPARATION_RU.md](PUBLICATION_PREPARATION_RU.md).

Read-only проверка Render ограничилась списком workspace. Провайдер вернул `no workspace selected` и требует явного выбора пользователем workspace до запросов к ресурсам. Поэтому тариф, expiration и реальный backup/PITR inventory не подтверждены; SQL к действующей базе не выполнялся.
