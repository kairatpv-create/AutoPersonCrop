# Подготовка публикации без развёртывания — 22.10.2026

iOS-проект и сборка отложены по указанию пользователя. Ни загрузки в магазины, ни создания нового приложения/Bundle ID, ни платежей, ни изменения инфраструктуры не выполнялось. Первый выпуск остаётся бесплатным.

## Что подготовлено в коде

- Android compileSdk/targetSdk 36 вместо 35. AGP 8.10.1, Kotlin 2.1.21, minSdk 26, версия 0.9.38 (71), applicationId `kz.kairat.organizer` сохранены. Ключи/подпись не трогались. Это debug-проверка, не release AAB.
- В настройках аккаунта — удаление с отдельным предупреждением, вводом email и повторного пароля. Кнопка не удаляет локальную базу/вложения; копии на других устройствах и экспортированные файлы остаются под контролем пользователя. Пароль не сохраняется через rememberSaveable.
- Серверный `POST /api/account/delete` повторно проверяет пароль, блокирует только текущего владельца и удаляет его строку с существующим `ON DELETE CASCADE` для sync. Аккаунт другого пользователя не изменяется. Старые JWT удалённого аккаунта отклоняются всеми защищёнными маршрутами через проверку существования пользователя.
- `/api/account` объявляет `accountDeletion:true`. Приложение на старом сервере сообщает о недоступности функции и не считает аккаунт удалённым при 404/неуспехе.
- Отдельный `/account-deletion` — внешняя страница удаления без необходимости устанавливать приложение. Она не показывает полноценную web-версию, не сохраняет пароль/token в browser storage, требует email/password/подтверждение. Это подготовленный исходник; действующий публичный URL удаления не подтверждён.
- API-ответы помечены `Cache-Control: no-store`.
- В приложении доступна справка «Данные и приватность» RU/EN с фактическим описанием локального хранения, синхронизации, разрешений, ограничений PIN/JSON/ZIP и контактом разработчика, уже присутствовавшим в исходниках.
- Новые PIN-защищённые напоминания скрывают заголовок/текст, не открывают полноэкранное окно с данными; notification/direct ReminderAlertActivity направляют в MainActivity с отдельным запросом PIN. Это не полное исправление D10 и не шифрование SQLite.

## Карта данных для проверки форм (не отправленная декларация)

| Категория | Подтверждённый путь |
|---|---|
| Email / user ID | Аккаунт на сервере; JWT содержит идентификатор/email; локальная привязка сохраняется после выхода |
| Пароль | Передаётся при входе/регистрации/подтверждении удаления по HTTPS; сервер хранит bcrypt hash. Сам пароль не включён в manual backup |
| Заметки, задачи, проекты, финансы, напоминания | SQLite; при входе облачный JSON v7 в PostgreSQL. Связаны с аккаунтом, пока синхронизация включена |
| Вложения и записи микрофона | Локальные файлы и ручная резервная копия. Текущий CloudSync их не передаёт |
| Календарь | Чтение с разрешения для функции календаря; отдельной загрузки всего системного календаря в CloudSync в исходниках нет |
| Системное распознавание речи | Вызывается Android RecognizerIntent; обработка зависит от выбранного поставщика. Проверить отдельно, не обещать полностью офлайн |
| Диагностика/IP/технические логи | Состав/сроки у хостинга не подтверждены; перед публикацией получить фактические параметры |
| Реклама / аналитика / платежи | SDK рекламы/аналитики/платежей в текущем Gradle нет. Подписки не добавлены |

Render — инфраструктурный обработчик, но исключения о «передаче» в конкретных формах необходимо сверить с фактическими условиями. PIN не надо описывать как шифрование; приложение не подключается к банковским счетам только из-за ручного финансового учёта.
