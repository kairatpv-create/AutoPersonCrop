# Политика конфиденциальности — «Закупки KZ — поиск»

Дата вступления в силу: 12 сентября 2026 года.

«Закупки KZ — поиск» — независимое неофициальное приложение для поиска и просмотра общедоступной информации о государственных закупках Республики Казахстан. Приложение не является приложением государственных органов Республики Казахстан и не представляет веб-портал государственных закупок.

## Источник данных

Приложение получает информацию из официального веб-портала государственных закупок Республики Казахстан https://procurement.gov.kz/ и его официального API https://ows.goszakup.gov.kz/.

## Какие данные используются

Приложение может обрабатывать введённый пользователем API-токен веб-портала государственных закупок, параметры поиска, пользовательские исключения и список избранного. Эти данные используются только для работы функций приложения.

API-токен и пользовательские настройки сохраняются локально на устройстве. Разработчик приложения не получает их на собственный сервер и не продаёт их третьим лицам.

Приложение обращается напрямую к официальному API государственных закупок для выполнения поисковых запросов и загрузки документов. Передача данных по сети выполняется по HTTPS.

## Что приложение не делает

Приложение не создаёт собственные учётные записи пользователей, не запрашивает доступ к контактам, фотографиям, геолокации, микрофону, камере, SMS или журналу звонков, не использует рекламные SDK и не продаёт пользовательские данные.

## Документы закупок

Документы, открываемые внутри приложения, могут временно сохраняться в приватном кэше приложения на устройстве для просмотра. Временные копии предназначены только для работы просмотрщика и не публикуются разработчиком.

## Хранение и удаление данных

Пользователь может удалить API-токен в настройках приложения. Остальные локальные данные удаляются при очистке данных приложения или его удалении с устройства. Серверного профиля пользователя у приложения нет.

## Безопасность

Приложение использует только сетевое разрешение INTERNET и не запрашивает лишние чувствительные разрешения Android. Резервное копирование данных приложения отключено, чтобы API-токен не переносился через резервную копию приложения.

## Изменения политики

При существенном изменении способов обработки данных эта политика будет обновлена до публикации соответствующей версии приложения.

## Контакт

Вопросы о конфиденциальности можно направлять разработчику через публичный раздел Issues: https://github.com/kairatpv-create/AutoPersonCrop/issues
