# Политика конфиденциальности — «Закупки KZ — поиск»

Дата вступления в силу: 12 сентября 2026 года.

«Закупки KZ — поиск» — независимое неофициальное приложение для поиска и просмотра общедоступной информации о государственных закупках Республики Казахстан. Приложение не является приложением государственных органов Республики Казахстан и не представляет веб-портал государственных закупок.

## Источник данных

Приложение использует официальный веб-портал государственных закупок Республики Казахстан https://procurement.gov.kz/ и его официальный API https://ows.goszakup.gov.kz/.

## Режим без токена

Базовый поиск может работать без API-токена через публичный раздел официального портала procurement.gov.kz, открываемый внутри приложения. При таком просмотре официальный портал может получать обычные технические данные веб-запроса и использовать собственные cookies в соответствии со своими правилами. Эти данные не передаются на сервер разработчика приложения.

## Расширенный режим API

Пользователь может по желанию самостоятельно получить и ввести собственный API-токен веб-портала государственных закупок. Токен используется только для расширенных функций приложения и прямых HTTPS-запросов к официальному API ows.goszakup.gov.kz.

API-токен, параметры поиска, пользовательские исключения и список избранного сохраняются локально на устройстве. Разработчик приложения не получает их на собственный сервер и не продаёт их третьим лицам.

## Что приложение не делает

Приложение не создаёт собственные учётные записи пользователей, не запрашивает доступ к контактам, фотографиям, геолокации, микрофону, камере, SMS или журналу звонков, не использует рекламные SDK и не продаёт пользовательские данные.

## Документы закупок

В расширенном режиме документы, открываемые внутри приложения, могут временно сохраняться в приватном кэше приложения на устройстве для просмотра. Временные копии предназначены только для работы просмотрщика и не публикуются разработчиком.

## Хранение и удаление данных

Пользователь может удалить API-токен в настройках приложения. Остальные локальные данные удаляются при очистке данных приложения или его удалении с устройства. Серверного профиля пользователя у приложения нет.

## Безопасность

Приложение использует только сетевое разрешение INTERNET и не запрашивает лишние чувствительные разрешения Android. Незашифрованный HTTP отключён. Резервное копирование данных приложения отключено, чтобы API-токен не переносился через резервную копию приложения.

## Изменения политики

При существенном изменении способов обработки данных эта политика будет обновлена до публикации соответствующей версии приложения.

## Контакт
