# AutoPersonCrop Android

Офлайн Android-приложение для массовой интеллектуальной обрезки JPEG-фотографий с людьми.

## Что делает

- выбирает целую папку через Android Storage Access Framework;
- рекурсивно ставит в очередь тысячи JPG/JPEG;
- определяет всех людей локально моделью YOLO11n / Google LiteRT;
- для портретного сюжета оставляет 5% сверху и снизу от общего контура людей;
- для широкого/лежачего сюжета оставляет 5% слева и справа;
- расширяет рамку до соотношения сторон текущего экрана телефона без растяжения изображения;
- никогда намеренно не режет найденного человека; если целевая рамка невозможна, сохраняет полный кадр;
- делает JPEG crop через libjpeg-turbo в коэффициентной области без декодирования/повторного JPEG-сжатия;
- фото без людей копирует байт-в-байт;
- оригиналы не изменяет, результаты пишет в `CROP`, сохраняя структуру подпапок;
- хранит очередь и продолжает после паузы/сбоя, не пересчитывая готовые фотографии.

## Сборка

Ветка `android-dev` автоматически собирается GitHub Actions. Перед Android-сборкой workflow экспортирует проверенный официальный `yolo11n.pt` в `person_detector.tflite`. SHA256 исходной модели закреплён в `tools/export_model.py`.

Toolchain: Android API 36, AGP 9.4.0, Gradle 9.6.0, JDK 17, NDK 28.2.13676358, LiteRT 2.1.5.
