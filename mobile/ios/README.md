# Organizer Pro for iPhone

Native SwiftUI client in the existing repository. Base: approved Android 0.9.40
(73). Android source, database, version and signature are unchanged.

- Open `OrganizerPro.xcodeproj`, scheme **OrganizerPro**, with Xcode 26+.
- iPhone, iOS 17.0+, RU/EN. Existing Bundle ID `com.organizerpro.mobile`, Apple
  app `6825404169`; no duplicate registration.
- Local `OrganizerCore` Swift package uses system SQLite and zlib. No third-party
  app SDKs, network sync, accounts, payments or ads.
- `swift test --package-path mobile/ios/OrganizerCore` runs wire/storage/reminder
  tests. Xcode integration/UI tests require an iOS simulator.
- `.github/workflows/organizer-ios.yml` records the actual Apple toolchain, tests
  synthetic data on small/large iPhones and builds an unsigned arm64 archive.
  An unsigned archive is not an installable or TestFlight-ready IPA.

The Xcode project is checked in. Regenerate after adding Swift source files:
`python3 tools/ios/generate_project.py`. Permission metadata is generated by
`tools/ios/generate_metadata.py`. The icon is derived from the approved Android
vector by `tools/ios/generate_assets.py` (Pillow/fontTools; PNGs are checked in).

`tools/ios/archive_signed.sh` requires an installed Apple Distribution identity,
the existing App Store profile, `IOS_TEAM_ID`, `IOS_PROFILE_NAME` and an unused
`IOS_BUILD_NUMBER`. It exports locally and never uploads or registers resources.
Do not commit signing assets or credentials.

See [BUILD_AND_TEST_RU.md](BUILD_AND_TEST_RU.md) for implementation and release steps.
