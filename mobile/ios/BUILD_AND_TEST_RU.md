# Organizer Pro — iPhone, сборка и TestFlight

Актуальный перенос от 23.10.2026. Основа — проверенный пользователем Android
0.9.40 (73), код `663b949f175ea380695cd967ce3e7c493c7b866e`.

## Исходники и архитектура

| Путь | Назначение |
| --- | --- |
| `mobile/android/` | Существующий Android; перенос его не изменяет |
| `mobile/ios/OrganizerPro.xcodeproj` | Настоящие app, integration test и UI test targets |
| `mobile/ios/OrganizerPro/` | SwiftUI и адаптеры Apple |
| `mobile/ios/OrganizerCore/` | Swift-модели, JSON/ZIP, SQLite, расчёт напоминаний |
| `mobile/ios/OrganizerCore/Tests/.../Fixtures/` | Искусственные копии настоящего Android BackupManager |
| `tools/ios/` | Генератор проекта, Android↔Swift probe, preflight и локальный signed export |
| `.github/workflows/organizer-ios.yml` | macOS CI: Core, iPhone UI, unsigned Release archive |

Выбраны SwiftUI и отдельный Swift-пакет. Ранее предложенный KMP framework не
существовал: его выделение потребовало бы одновременно менять работающий
Android и вводить ещё одну цепочку сборки. Повторно используются wire-формат,
восемь коллекций, правила валидации, синтетические Android fixtures, утверждённая
иконка и палитра. Swift проверяется против настоящего Android-кода. APK не
используется как iOS binary.

## Действующие продуктовые решения

Заметки, задачи, проекты, финансы, этапы/журнал/связанные заметки, вложения;
RU/EN, обе темы, раздельные размеры текста и кнопок, жирный шрифт; PIN, Files,
отправка полной копии через выбранное почтовое приложение, восстановление
JSON/ZIP и сохранённого вложения. Адаптеры Apple: камера, PhotosPicker, файлы,
голосовая запись/проигрывание, диктовка, уведомления, календарь и дни рождения.

По последнему решению пользователя нет аккаунта, синхронизации и пункта
веб-страницы. Нет переключателя архива: полная копия включает вложения. Нет
подписок, платежей, рекламы или SDK аналитики. Первый выпуск бесплатный.
Render и PostgreSQL не изменяются; данные прежних аккаунтов не удаляются.

## Сохранность данных

На iPhone отдельный `organizer-ios.sqlite`, schema 1: JSON метаданных и BLOB
вложений. Метаданные, байты и страховочная копия меняются в одной
`BEGIN IMMEDIATE` транзакции, WAL + synchronous FULL. Нет отдельной публикации
каталога файлов после COMMIT.

Формат `my-organizer-backup`: локальные версии 3–6 и cloud snapshot 7. Экспорт —
полный JSON v6 в обычном ZIP. Все восемь коллекций обязательны; у локального
файла обязательны settings и attachments. Проверяются типы, точные целые ID,
дубликаты, имена/размеры/Base64 вложений, CRC, размер и сложность JSON/ZIP до
изменения базы. `{"notes":[]}` не является копией. Полная пустая копия корректна,
показывается как пустая и требует явного подтверждения.

У snapshot 7 отсутствие settings сохраняет настройки устройства. Отсутствие
attachments сохраняет прежние вложения только при совпадении владельцев по ID
и createdAt, иначе восстановление отклоняется. Это импорт старого снимка,
а не активная синхронизация. Перед заменой сохраняется проверенная страховочная
копия в той же транзакции; она доступна через меню восстановления. Ошибка или
аварийное завершение до COMMIT возвращает прежние записи и вложения целиком.

Удаление проекта сохраняет финансовые записи. Суммы Android не округляются
при импорте; итоги считаются через Decimal. Черновики сохраняются при вводе.
PIN, Keychain и черновики не входят в копии. Application Support исключён из
системного backup: регулярно сохраняйте полную копию через приложение.
Android→iPhone: сохранить файл на Android, перенести через Files/e-mail,
проверить состав на iPhone, подтвердить восстановление.

## Защита и разрешения

PIN: Keychain WhenUnlockedThisDeviceOnly, PBKDF2-HMAC-SHA256, 210000 итераций,
случайная соль, сравнение без раннего выхода; пять ошибок → пауза 30 секунд с
сохранением состояния. Недоступность/повреждение защищённой записи не открывает
интерфейс. Отдельное окно закрывает также редакторы и вложения при уходе из
приложения. PIN защищает интерфейс; базу шифрует iOS Data Protection.
Пользовательский JSON/ZIP не зашифрован PIN-кодом.

Разрешения запрашиваются при выборе функции. PhotosPicker не требует общего
доступа к медиатеке; EventKit используется только для чтения. После ошибки
сохранения аудиофайл остаётся для повторного добавления. Диктовка предпочитает
обработку на устройстве; при её недоступности может использовать службы Apple
онлайн, о чём сообщают интерфейс и purpose strings. Нет чтения почтового ящика,
запроса пароля e-mail или автоматической отправки писем.

PrivacyInfo.xcprivacy включён в app. File Timestamp reason C617.1 относится к
метаданным файлов собственного контейнера. Ответы App Privacy, публичный URL
политики и сведения оператора проверяются перед отправкой; manifest не заменяет
этих сведений. Контакт из существующего приложения: kairat.pv@gmail.com.

## Сборка и проверка

Минимальная ОС iOS 17.0, iPhone. CI выбирает фактически доступный runtime и
создаёт маленький iPhone SE (3rd generation) и большой Pro Max. Точные Xcode,
SDK, runtime и модели сохраняются в артефактах.

```bash
swift test --package-path mobile/ios/OrganizerCore
python3 tools/ios/generate_project.py
bash tools/ios/preflight.sh
```

В Xcode выбрать scheme OrganizerPro → Test. Проверки: wire/SQLite/напоминания,
Keychain, импорт и неизменность данных при отказе; создание записей и черновики;
PIN поверх редактора; RU/EN, темы и крупный шрифт. Отдельный process-death probe
завершает процесс после записи замены до COMMIT, затем новый процесс сверяет
исходные данные и вложения. Android bridge восстанавливает Swift-экспорт
настоящим Android BackupManager на host SQLite. Только искусственные данные.

DEBUG UI tests используют отдельный UUID-каталог и namespace Keychain.
Синтетические флаги и fixtures исключаются из Release, что проверяется отдельно.
Автоматические результаты относятся к конкретному CI run и записываются в
итоговый отчёт. Они не подменяют тест физического iPhone: камера/микрофон,
диктовка RU/EN, уведомления при Focus/блокировке, фон, реальный почтовый клиент
и большая копия на маломощном устройстве требуют проверки на телефоне.

Повторы каждый час используют локальные уведомления, а не Android full-screen
alarm. Бюджет — 64 ближайших сигнала. При большом числе повторов периодически
открывайте приложение; BGAppRefresh назначает система и не гарантирует точное
время исполнения. Звук, вибрацию и вид уведомления контролирует iOS.

подписанный archive и локальный IPA, не создаёт Apple-ресурсов и не загружает
сборку. Private key, p12/password, профиль и API p8 не хранить в Git.
