МОЙ ОРГАНАЙЗЕР v0.8.0 — ИСХОДНИК

База восстановлена по реально установленной стабильной v0.7.4.
Пакет сохранён: kz.kairat.organizer
Версия: 0.8.0 (versionCode 23)
База данных: organizer.db, schema version 4 — без destructive migration.

ЧТО ИЗМЕНЕНО В 0.8.0
- «Проекты» скрыты из интерфейса. Таблица/модель остаются для совместимости старых данных и резервных копий.
- Добавлен выбор языка RU / KK.
- Диктовка заменена настоящей голосовой заметкой: старт/стоп записи, сохранение M4A, проигрывание, длительность, волна.
- В сохранённом аудиоблоке нет значка микрофона: только Play/Pause, волна и время.
- В редакторе кнопки «Вложение» и «Записать» занимают 50/50 ширины.
- «Сохранить» занимает всю ширину.
- Аудиофайлы включаются в JSON-резервную копию вместе с вложениями.

КАК СОБРАТЬ — САМЫЙ ПРОСТОЙ СПОСОБ
1. Распаковать архив на компьютер, где уже установлен Android Studio/Android SDK.
2. Дважды нажать BUILD_TEST_APK.bat.
3. Скрипт сам найдёт Android SDK, при необходимости один раз скачает Gradle 8.11.1, выполнит assembleDebug и положит готовый файл MyOrganizer-v0.8.0-debug.apk рядом со скриптом.

АЛЬТЕРНАТИВА
Открыть папку в Android Studio -> дождаться Gradle Sync -> Build -> Build APK(s).
APK будет в app/build/outputs/apk/debug/app-debug.apk.

ВАЖНО ПРО ОБНОВЛЕНИЕ ПОВЕРХ v0.7.4
Android требует ту же цифровую подпись. Если v0.7.4 была подписана тем же debug/release keystore на вашем ПК, v0.8.0 установится как обновление и сохранит данные. Если подпись другая, сначала в v0.7.4 сделайте резервную копию, затем установите v0.8.0 начисто и восстановите копию.
